# QuickFix

Platformă de management operațional pentru o firmă de reparații și intervenții la domiciliu.

## MVP
- Dashboard operațional
- Intervenții
- Programări
- Clienți
- Tehnicieni
- Stoc materiale
- Rapoarte

## Roadmap
1. Bază de date
2. Autentificare Admin / Dispecer / Tehnician
3. CRUD real pentru intervenții și clienți
4. Hartă și alocare tehnicieni
5. Notificări
6. Devize și facturare
7. Aplicație mobilă pentru tehnicieni
